# bag_tag
Created for the half-life program by Hack Club, bag_tag is an accessory inspired by content seen online and features a relatively large oled screen and a 110 maH LiPO cell alongside 3 low profile switches for some basic control. I aim to have the device easily configurable over BLE to allow for easy addition of your favorite memes and animations to the display! It'll also have an info page for owner info and whatever you want on there!
